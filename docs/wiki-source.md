## どんな機能か

作物の収穫・採掘・釣り・戦闘などの行動が経験値になり、スキルのレベルが上がる RPG 要素。レベルが上がると、能力値（stats）が伸び、スキルごとのアビリティが解放される。**資源サーバーだけに入っている。一般サーバーには入っていない**（2026-11-17・本番の plugins の jar で確認）。

有効なワールドは、資源サーバーの全ワールド（資源ワールド・ネザー・エンド）。`config.yml` の `blocked_worlds` / `disabled_worlds` には `Example` だけが入っている。

## プレイヤーの使い方

1. 資源サーバーで角鯖メニューを開く（資源の `CommandPanels/panels/root.yml` の `skill` ボタン。表示名「スキル」、スロット 3。2026-11-17 確認）
2. 「スキル」を押すと、スキルの一覧が開く
3. 各スキルを押すと、レベル・経験値・解放したアビリティが見られる

- 経験値が入ると、画面上部にボスバーでスキル名と進み具合が出る（`boss_bar.enabled: true`、`mode: single`、`stay_time: 60`）。アクションバーは無効
- レベルが上がると、画面中央にタイトルが出て、レベルアップ音（`ENTITY_PLAYER_LEVELUP`）が鳴る（`leveler.title.enabled` / `leveler.sound.enabled`）

## 数値

### スキルの種類（本番で有効なのは 11 種）

`skills.yml` に載っているのは、農耕・伐採・採掘・釣り・掘削・射撃・防御・戦闘・敏捷性・錬金術・エンチャントの 11 種。すべて `max_level: 100`。メッセージファイルにあるスタミナ・ソーサリー・ヒーリング・フォージングは、`skills.yml` に無いので存在しない（マナは `mana.enabled: false` で無効）。

### 必要な経験値

`xp_requirements.yml`: `multiplier * (level - 2) ^ 2 + base`、`multiplier: 100`、`base: 100`。`XpRequirementsLoader` が `level` に i+2 を入れて並べるため、実質、現在のレベル L から L+1 に上がるのに **100 × L² + 100**。

|---|---|---|
| 1 | 100 | 100 |
| 5 | 3,500 | 1,700 |
| 10 | 29,500 | 8,200 |
| 25 | 492,500 | 57,700 |
| 50 | 4,047,500 | 240,200 |
| 100 | 32,845,000 | 980,100 |

### アビリティ

`config.yml` の `start_level: 0` なので、`abilities.yml` の `unlock: '{start}+N'` は **レベル N で解放**（`AbilityLoader.java:65`）。スキルごと 9 つが、レベル 1〜9 に 1 つずつ。`level_up: 9` で、解放後は 9 レベルごとに効果が上がる。`max_level: 0` は上限なし（受け流しだけ 20）。操作が要るもの: 二刀流（オフハンドに武器を持って右クリック）、トンネル掘進（スニーク中に石系を掘る）、空中ダッシュ（落下中にスニーク。8 秒クールダウン）。先制攻撃は `cooldown_ticks: 6000`（5 分）。

### 敵を倒す経験値の減額（`config.yml` の `source.entity.trap_protection`、改造部分）

動かないモブ・プレイヤー製ゴーレム・乗り物に乗ったモブ・ボートからの攻撃・足止め・詰め込み（`max_crammed_entities: 5`）・隙間や物陰からの攻撃・水流・届かない位置・同じ場所での連続撃破（`stationary_kill_limit: 10`、半径 8 ブロック）・自分以外のダメージ・棘のみで倒した、は減額か 0。`min_legit_damage_ratio: 0.7`。画面には理由が出る（`messages_ja.yml` の `xp_reduction.reason`）。

### LevelledMobs との連動（`config.yml` の `hooks.LevelledMobs`）

敵のレベルで、スキル経験値が `1 + (レベル - 1) × 0.1` 倍（`xp_multiplier: 0.1`、`max_multiplier: 0.0` で上限なし。`LevelledMobsHook.java:46-91`）。LevelledMobs の「チャンクの撃破上限」に達した敵は、経験値 0 倍（`respect_chunk_kill_max: true`）。

### パーティー機能（`config.yml` の `party`）

- **開き方**: スキルメニュー（`/skills`）の「パーティー」ボタン、または `/party` コマンドから専用メニューを開く。
- **メンバー管理**: パーティーの作成・招待・承認/辞退・脱退・キック・リーダー委譲・解散に対応。上限人数はデフォルト無制限（`max_size: 0`）。ログアウト後 `300秒` 以内の再ログインで自動復帰し、超過で自動離脱（リーダー不在時はオンラインメンバーへ自動委譲）。
- **招待権限・受信ブロック**: 招待はデフォルトでリーダーのみ（リーダーがメニューからメンバー招待許可を ON/OFF 切替可能）。個人設定として「招待ブロック」の ON/OFF 切替も可能。
- **スキル経験値の共有**:
  - 戦闘・採取系スキルが対象（`alchemy`, `enchanting`, `agility`, `endurance`, `sorcery`, `healing`, `forging` はデフォルト除外）。
  - 採取系は獲得者本人に近距離メンバー1人あたり +5%（最大 +15%）のボーナス、同じワールドの半径 48 ブロック以内のメンバーへ元経験値の 35%（大人数時は合計 105% 上限で案分）を共有。
  - モブ撃破時は、周囲 64 ブロック以内のパーティーメンバーに人数ボーナス（+10%/人、最大 +30%）を加えた上で「均等 50% ＋ ダメージ比例 50%」でスキル経験値とバニラ経験値を配分。
- **誤爆防止（フレンドリーファイア無効）**: デフォルト ON（リーダーがメニューで ON/OFF 切替可）。パーティーメンバーへの直接攻撃・矢やトライデント等の投射物・飼いならしペット・有害ポーション/残留効果・範囲スキル（サンダーフォール、シャープフック等）を無効化。
